# perancangan-jaringan-client-server-menggunakan-cisco-packet-tracer
1. Perangkat Utama & Penghubung 🛜🎀Router3 (Cisco 2811): Si otak utama atau gateway yang menghubungkan dua dunia berbeda, yaitu jaringan server dan jaringan switch lokal. Router ini punya dua pintu utama (fa0/0 dan fa0/1) 🚪✨Switch5 (Cisco 2960): Si pusat keramaian (hub lokal) yang menyatukan semua komputer (PC) di sekitarnya membentuk bintang gemas (Star) 🌟   2. Pembagian Segmen Jaringan (Subnet) 🌐🧁Topologi ini memakai subnet mask /16 (255.255.0.0) dan dibagi menjadi beberapa wilayah lucu:Area Server (10.1.x.x): Server0 terhubung langsung ke pintu fa0/0 di Router3 dengan IP 10.1.1.1. Wilayah ini jadi pusat penyimpanan data atau aplikasi utama ☁️💖Area Switch / PC (10.2.x.x & 10.3.x.x): Empat komputer gemas (PC0, PC1, PC2, dan PC3) berkumpul di bawah Switch5, tapi dibagi jadi dua geng IP yang berbeda:Geng Kiri — PC0 & PC1 (10.2.x.x): Nempel di port fa0/6 dan fa0/7 💻🌷Geng Kanan — PC2 & PC3 (10.3.x.x): Nempel di port fa0/11 dan fa0/12 💻🎀   3. Cara Kerja Komunikasi Data 🚀💫Ngobrol Sesama PC (Satu Switch): Komputer-komputer di bawah Switch5 bisa langsung saling kirim pesan lewat Switch5 tanpa perlu permisi ke router 💬✨PC Mau Main ke Server: Kalau salah satu PC mau akses Server0, datanya harus mampir dulu ke Switch5, naik ke Router3 lewat pintu fa0/1, lalu keluar lewat pintu fa0/0 menuju Server0. Karena alamat jaringan mereka berbeda segmen, Router3 wajib hadir sebagai pintu gerbang (default gateway) biar datanya bisa menyeberang dengan selamat dan lancarr
